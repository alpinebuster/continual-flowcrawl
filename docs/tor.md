# Tor (The Onion Router)
通过多层加密“接力转发”，让别人很难知道你是谁、你在访问什么网站。

## How it works?
在普通上网中：

```txt
你 → 网站
```

问题是：

ISP 能看到你访问的网站
网站能看到你的 IP
网络中间人可以分析流量

---

Tor 的核心是洋葱路由（Onion Routing）

意思是：数据像洋葱一样一层一层加密。

它的工作流程：

```txt
你
 ↓
入口节点（Guard Node）
 ↓
中继节点（Relay Node）
 ↓
出口节点（Exit Node）
 ↓
目标网站
```

每一跳只知道“上一跳和下一跳”，不知道完整路径，因此能隐藏：

你的真实 IP
你的地理位置
访问网站的来源

---

Tor 和 VPN 的区别

VPN：
```txt
你 → VPN → 网站
```

VPN 公司知道你是谁

Tor：
```txt
多个节点分散
没有单点知道完整路径
```
